# Telegram Circle Wall — MVP

Простий MVP: Telegram-бот приймає відеоповідомлення ("кружечки"), а веб-екран показує їх у реальному часі.

## 1. Встановлення

Потрібен Python 3.10+.

```bash
pip install -r requirements.txt
```

## 2. Створення Telegram-бота

У Telegram відкрий `@BotFather`, створи бота через `/newbot` і скопіюй токен.

Створи файл `.env` у корені проєкту:

```env
BOT_TOKEN=ВСТАВ_СЮДИ_ТОКЕН
HOST=0.0.0.0
PORT=8000
```

## 3. Запуск

```bash
python app.py
```

Після запуску:
- бот приймає кружечки;
- екран відкривається на `http://localhost:8000`;
- якщо телевізор/інший пристрій знаходиться в тій самій Wi-Fi мережі, відкрий `http://IP_КОМП'ЮТЕРА:8000`.

Наприклад:
`http://192.168.1.25:8000`

## 4. Як користуватися

Надішли боту відеоповідомлення-кружечок.

На екрані новий кружечок з'явиться автоматично. Відео програється один раз великим по центру, після чого залишається в сітці.

## Важливо

Це локальний MVP: відео зберігаються на комп'ютері, де запущений бот. Для справжнього публічного ресурсу з доступом через інтернет потрібен сервер/VPS і HTTPS.
